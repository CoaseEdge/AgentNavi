# 开发路线

## 0.1：三层架构基线（已完成）

- 外置项目注册表与 SQLite 图模型；
- L1 物理依赖；
- 保守 L2；
- Hook 构造 L3；
- 查询、影响、历史和 Obsidian 投影。

## 0.2：可靠历史、价值验证与人工 Overlay（已完成基线）

- L3 append-only JSONL；
- 日志优先写入、校验、回填和幂等重放；
- 数据库完全丢失后的任务、事件、会话和 affects 恢复；
- 可重复候选文件基准；
- 真实 Agent Token、耗时和成功状态记录；
- 召回率与成功状态质量门槛；
- L2 候选审查；
- 接受、拒绝、重命名、别名、合并和文件映射；
- 人工 Overlay 独立追加日志与数据库重建恢复。

仍需补强：

- schema migration 框架；
- 文件移动与重命名身份继承；
- 敏感字段脱敏；
- 索引预算与超时；
- 自动获取更多 Agent 的真实 Token 统计。

## 0.3：更深 L1 解析

- Tree-sitter 插件；
- Go、Rust、Java、C#、PHP 等；
- API 路由、数据库表、配置键；
- 符号级调用图；
- 写作引用和文献；
- 视频时间线和素材关系。

## 0.4：语义审查工作台

- 图形化候选队列；
- 证据查看和批量接受/拒绝；
- 概念拆分；
- 团队审批和审计；
- 置信度校准与关系衰减；
- Obsidian 批注导入。

## 0.5：Context Service

- 本地 HTTP API；
- MCP Server；
- 统一 query / context / impact / history；
- 远程沙箱受控访问；
- 项目、路径和 Agent 权限；
- Dispatcher 上下文路由。

## 0.6：跨项目 Work Graph

- 跨项目同义概念；
- 项目间依赖和复用；
- 个人与组织任务历史；
- 决策、产品、代码、研究和写作资产联动。

## 持续评估指标

- 首次有效修改前读取文件数；
- 探索 Token；
- 无关读取比例；
- 必要文件召回；
- 任务成功率；
- 完成时延；
- 图谱错误率与人工纠正率；
- 索引成本/收益比。
