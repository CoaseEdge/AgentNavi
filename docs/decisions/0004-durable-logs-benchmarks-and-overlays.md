# ADR 0004：权威日志、质量门槛与人工 Overlay

## 状态

已接受。

## 背景

仅把 L3 和人工语义判断放在 SQLite 中，会使“图谱可重建”成为不完整承诺；只比较候选数量，又会把漏读必要文件误报为节省；把人工修改直接写入自动图，则会在重建时丢失或与推断混杂。

## 决策

1. L3 事件先写 append-only `events.jsonl`，SQLite 是物化视图；
2. 人工语义校正先写 append-only `semantic-overlays.jsonl`，自动 L2 与人工 Overlay 分离；
3. 基准同时记录必要文件召回和任务成功；只有双方召回率至少 95%，且真实对照双方成功时，才计算正式节省。

## 后果

优点：

- 数据库可删除重建；
- 人工决定不会被扫描覆盖；
- 节省结论具备最低质量约束；
- 所有人工校正可审计和撤销。

代价：

- 需要维护日志 schema 和重放器；
- JSONL 可能包含敏感任务信息；
- 用户需要准备必要文件集合和真实 Token，才能完成严格对照；
- 人工 Overlay 冲突必须有明确优先级。
