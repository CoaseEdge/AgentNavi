# ADR-0001：图谱作为外置派生状态

- 状态：已接受
- 日期：2026-08-14

## 决策

AgentNavi 的项目图谱保存在项目仓库之外。项目仓库、Git 和 Agent 原始事件是事实来源，图谱是可重建派生状态。

## 原因

- 不污染任意代码、写作、视频或研究项目；
- 一套引擎服务多个项目；
- 更换 Agent 和 Obsidian 不影响底层；
- 可以集中做跨项目查询；
- 删除图谱不影响项目运行。

## 代价

- 本地路径迁移需要更新项目注册表；
- 图谱不会天然跟随仓库 clone；
- 远程 Agent 需要未来的 Context Service；
- L3 需要独立事件日志才能做到完全可重建。
