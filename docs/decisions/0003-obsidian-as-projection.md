# ADR-0003：Obsidian 作为生成视图而非底层数据库

- 状态：已接受
- 日期：2026-08-14

## 决策

SQLite 保存结构化图谱，Obsidian Markdown 由导出器单向生成。

## 原因

- Agent 不应依赖 Obsidian App 是否启动；
- 云端或无桌面环境仍可查询图谱；
- SQLite 更适合增量更新、证据、置信度和并发；
- Obsidian 保留其最擅长的人类浏览、链接和图视图能力。

## 代价

- 当前不能在 Obsidian 中直接维护图谱；
- 需要生成稳定文件名和链接；
- 人工校正需要未来的 Overlay 或批注导入机制。
